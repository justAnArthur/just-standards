# Príklad Rent (example)

A fictional car and van rental in Bratislava, built as the "after" of the just-standards example: the same Next.js
scaffold as [`../rental-before`](../rental-before), grown into a site that meets the standards in [`../../packs`](../../packs).
Nothing here is a real company: the name, the IČO 12 345 678, the addresses, the `+421 2 000 000 0x` numbers, the
`@example.com` addresses and the prices are examples, and the site says so in its footer.

```bash
bun install
bun run build && bun run start   # http://localhost:3102
```

How it is built, the commands and the rules: [AGENTS.md](AGENTS.md). The design system: [DESIGN.md](DESIGN.md). Brand
files: [brand/](brand/README.md). Copy and facts: [`content/`](content).
