# Topic vocabulary

GitHub rules: lowercase, digits and hyphens, ≤ 50 chars each, ≤ 20 per repo. Aim for 3–8.
Pick from these lists; add a new term only when nothing here fits, and prefer the term GitHub
already suggests for that technology.

## kind — exactly one

library · cli · app · website · template · github-action · plugin · notebook ·
coursework · hackathon · thesis · notes · experiment

## stack — 1 to 4, most specific first

typescript · javascript · python · java · kotlin · rust · c · tex · tcl · mips-assembly ·
bun · node · react · preact · nextjs · vue · expo · react-native · tauri · vite ·
payload-cms · strapi · medusajs · drizzle · postgresql · sqlite · spring · javafx ·
maplibre · pytorch · tensorflow · jupyter · docker

## domain — 1 to 3

design-system · ui-components · ci-cd · release-automation · monorepo · ai-agents · llm ·
maps · geospatial · pdf · seo · i18n · cms · networking · protocol · algorithms ·
data-structures · machine-learning · computer-vision · super-resolution · image-restoration ·
trading-bot · polymarket · youtrack · intellij-plugin · obsidian · messaging · avatar · audio

## context — optional

- University coursework: always `fiit-stu` (confirmed: FIIT STU, Bratislava). Name the course in
  English in the README and banner; take the code from file names (`UI_01_…zip`, `VPWA …`) and the
  name from the report's own header. Codes seen so far: UI (Artificial Intelligence), PKS (Computer
  and Communication Networks), DSA (Data Structures and Algorithms), OOP (Object-Oriented Programming),
  DBS (Database Systems), VPWA (Development of Progressive Web Applications), IAU (Intelligent Data
  Analysis), MIP (Methods of Engineering Work), ZOOP (Fundamentals of Object-Oriented Programming),
  PPI (Principles of Computer Engineering, unconfirmed), TZIV (English name unknown; use the code). If a code isn't in this list, read the report; never guess.
- Hackathons: `hackyeah` plus the year, e.g. `hackyeah-2025`.
